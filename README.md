# 🤖 Spot A.I. — Generative AI Chatbot Project
### CSIT357 | Machine Learning Final Project

---

## 📌 Overview

**Spot A.I.** is a Generative AI chatbot project developed as part of CSIT357.
This project explores the fundamentals of conversational AI and large language
models, demonstrating how modern generative AI techniques can be applied to
build intelligent, responsive assistants.

## 🎯 Project Goals

- Understand and apply Generative AI concepts to a chatbot use case
- Explore how large language models (LLMs) power conversational assistants
- Build and demonstrate a functional AI chatbot pipeline
- Present findings and results in a structured academic format
